# experiments

Carpeta de investigacion del proyecto.

Aqui viven notebooks y scripts para probar ideas sin tocar el pipeline productivo.

## Subcarpetas

- `detection/`: analisis de entrenamiento YOLO.
- `positions/`: dataset y pruebas de roles posicionales.
- `possession/`: heuristicas de posesion sobre tracking ya generado.
- `reference_points/`: pruebas de homografia y bird-eye view.
- `tracking/`: depuracion puntual del tracker.
- `visualization/`: notebooks de analisis visual.

Los experimentos se apoyan en `football_ai/`, pero no sustituyen a los scripts principales de `scripts/`.
