# experiments/possession

Experimentos de posesion a partir del tracking.

## Que hace

`team_possession.py` estima por frame que equipo controla el balon usando la trayectoria del balon, la distancia a jugadores cercanos y reglas temporales de estabilidad.

## Salidas

- CSV y JSON por frame con la posesion estimada.
- Video anotado con el equipo poseedor.
