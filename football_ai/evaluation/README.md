# evaluation

Modulo de metricas y visualizacion para analizar resultados del tracking.

## Que incluye

- `evaluator.py`: calcula metricas por track y resumenes globales.
- `experiment_visualizer.py`: compara varias ejecuciones.
- `metrics_visualizer.py`: grafica metricas temporales.
- `track_visualizer.py`: analiza distribuciones por track.
- `cluster_visualizer.py`: revisa colores y clusters de camisetas.

Se usa sobre todo desde notebooks y scripts de analisis.
