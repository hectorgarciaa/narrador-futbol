# models

Carpeta de pesos y checkpoints del proyecto.

## Contenido habitual

- `yolo/`: modelos base de deteccion.
- `finetuning/`: pesos afinados para futbol.
- `finetuning-balon/`: pesos especificos para el balon.
- `positions/`: modelos de roles posicionales.
- `pnlcalib/`: pesos auxiliares para calibracion de campo.
- `gguf/` y `qwen_voices/`: assets usados por comentarios y voz.

Las rutas concretas que usa el codigo se definen en `config.yaml`.
