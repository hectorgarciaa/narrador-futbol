# data

Datos de entrada del proyecto.

## Contenido

- `detection/`: datasets para deteccion en formato YOLO.
- `partidoPrueba/`: videos de prueba para deteccion y tracking.
- `partidosPosiciones/`: clips usados para construir el dataset de roles.
- `posiciones_etiquetadas/`: dataset etiquetado derivado de esos clips.

## Nota

Por tamano, muchos de estos archivos no se versionan completos en git. Las rutas operativas se resuelven desde `config.yaml`.
